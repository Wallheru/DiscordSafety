FLOWSTATE MAIN2 — UPDATED FULL PROJECT

This ZIP contains the complete repository, with all original project files plus these updates:

- Pricing cards now reflect actual implemented features and the 1,000-workflow server safety cap.
- Front-end Pro/Team workflow limits match the server.
- The server blocks a second active Pro purchase.
- Accounts with Team access cannot buy Pro or Team again while that Team access is active.
- The Pro card hides its purchase button while Pro is active.
- A live countdown shows the next Pro renewal, or the date Pro access ends if cancellation is scheduled.
- The website periodically refreshes account status after the billing period ends.
- Stripe webhook saves cancellation scheduling fields; /api/me exposes them.

SETUP
- Extract this ZIP.
- Upload/push the contents of the DiscordSafety-main2 folder to your GitHub repository branch main2 (keep the existing folder structure).
- Netlify should deploy from GitHub automatically.
- Keep all secrets in Netlify environment variables. No secrets are included in this ZIP.

IMPORTANT BILLING BEHAVIOR
- If Pro auto-renews, the timer says "Next Pro renewal in ...".
- If cancellation at period end is scheduled in Stripe, it says "Pro access ends in ...".
- When Stripe reports the subscription as canceled, the existing subscription logic returns the account to Starter.
- Stripe webhook endpoint must continue receiving customer.subscription.updated and customer.subscription.deleted events.
- Team access includes Pro features, so active Team members cannot purchase a duplicate Pro or Team plan.
